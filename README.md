# National Weather Big Data Analytics Platform (NWIP)

Reconstructed from the exported Greta project bundle — SIH Problem Statement 26069
(Ministry of Earth Sciences / India Meteorological Department, Disaster Management).

React + TypeScript + Vite frontend (shadcn/ui, Tailwind, React Router, TanStack Query,
Leaflet, Recharts) with a FastAPI + MongoDB backend.

## Project structure

```
nwip-project/
├── backend/
│   ├── server.py            # FastAPI app (status-check API scaffold)
│   ├── requirements.txt
│   └── .env.example         # copy to .env and adjust
└── frontend/
    ├── src/
    │   ├── pages/            # Overview, LiveWeather, Reports, WeatherEvents,
    │   │                      # Analytics, GisMap, Verification, DataSources, AdminPanel
    │   ├── components/
    │   │   ├── layout/        # AppLayout, Header, Sidebar
    │   │   └── ui/             # shadcn/ui component library
    │   ├── data/mockData.ts
    │   └── config.ts          # API_URL — empty in dev (Vite proxies /api), injected in prod
    ├── package.json
    └── .env.example / .env.production.example
```

## Prerequisites

- Node.js 18+ and [Bun](https://bun.sh) (the project ships a `bun.lock`; `npm`/`pnpm` will
  also work if you delete `bun.lock` and generate a fresh lockfile)
- Python 3.10+
- A running MongoDB instance (local or Atlas)

## Backend setup

```bash
cd backend
cp .env.example .env        # edit MONGO_URL / DB_NAME / CORS_ORIGINS as needed
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn server:app --reload --port 8000
```

## Frontend setup

```bash
cd frontend
cp .env.example .env                          # VITE_BACKEND_URL blank = use Vite's dev proxy
cp .env.production.example .env.production     # set your deployed API URL before building
bun install      # or: npm install
bun dev          # or: npm run dev
```

The app runs at `http://localhost:5173`. In development, `VITE_BACKEND_URL` is left blank
and API calls to `/api/*` are expected to be proxied to the FastAPI backend — add a proxy
entry in `vite.config.ts` (`server.proxy`) pointing `/api` at `http://localhost:8000` if
you're running both locally, or set `VITE_BACKEND_URL` directly to `http://localhost:8000`.

## Notes

- `backend/server.py` currently only implements the boilerplate `/api/status` health-check
  routes from the Greta starter template — the weather-report endpoints (ingestion,
  verification, analytics) described in the problem statement still need to be built out
  and wired to `frontend/src/data/mockData.ts`'s shape.
- `.env` files were regenerated as `.env.example` — copy them before running; the real
  `.env` files are git-ignored so local secrets never get committed.
- `frontend/dist-static/` is a previously built output bundle; it's git-ignored and will
  be regenerated by `bun run build`.
